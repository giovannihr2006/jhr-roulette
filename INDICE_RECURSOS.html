🎯 Casos de Uso - ¿Cómo Proceder?

📱 CASO 1: Quiero jugar ahora mismo

Objetivo: Probar el juego inmediatamente

→ ACCIÓN:

  1. Abre index-3d.html en tu navegador
  2. Presiona ESPACIO para giro de prueba
  3. Usa 1-4 para cambiar cámaras
  4. Presiona M para música

Alternativa 2D: Abre index.html para versión clásica
